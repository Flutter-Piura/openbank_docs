# Contribuir a OpenBank Docs

1. Revisa documentos y ADR existentes.
2. Enlaza un issue para cambios de alcance o decisiones significativas.
3. Crea una rama corta desde `main` y usa Conventional Commits.
4. No incluyas secretos, datos reales ni afirmaciones regulatorias no verificadas.

Ejemplos:

```text
docs(architecture): record state management decision
docs(roadmap): clarify MVP exit criteria
fix(plan): correct repository compatibility matrix
```

Los ADR aceptados no se reescriben para ocultar una decisión anterior: se reemplazan mediante un nuevo ADR que explique el cambio. Verifica enlaces, bloques de código y consistencia con los repositorios afectados.

Al participar aceptas el [Código de conducta](CODE_OF_CONDUCT.md).
