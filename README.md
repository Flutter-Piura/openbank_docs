# OpenBank Docs

Documentación transversal de OpenBank, proyecto bancario educativo y open source de Flutter Piura.

OpenBank trabaja exclusivamente con identidades, cuentas y dinero ficticios. No es un banco real, no procesa dinero y no debe utilizarse como plataforma financiera de producción.
